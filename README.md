# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# 🛍️ ShopEase – E-Commerce Web Application

ShopEase is a responsive e-commerce web application built using React and Tailwind CSS. It provides a simple shopping interface where users can explore products, filter them by category, view product details, and manage product listings.

## 🚀 Features

- **Product Listing:** Browse a collection of products.
- **Category Filtering:** Filter products based on categories.
- **Product Details:** View individual product information.
- **Add Products:** Add new products to the collection.
- **Edit Products:** Update existing product information.
- **Delete Products:** Remove products from the collection.
- **Persistent Storage:** Uses browser LocalStorage to retain product data across page refreshes.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **React Router:** Navigate between different pages of the application.

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Context API
- React Router DOM
- Axios
- React Toastify
- LocalStorage
