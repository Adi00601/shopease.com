# 🛍️ ShopEase – E-Commerce Web Application

ShopEase is a responsive e-commerce web application built using React and Tailwind CSS. It provides a simple shopping interface where users can explore products, filter them by category, view product details, and manage product listings.

## 🚀 Features

- **Product Listing:** Browse a collection of products.
- **Category Filtering:** Filter products based on categories.
- **Product Details:** View individual product information.
- **Add Products:** Add new products to the collection.
- **Edit Products:** Update existing product information.
- **Delete Products:** Remove products from the collection.
- **Persistent Storage:** Uses browser LocalStorage to retain product data across page refreshes.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **React Router:** Navigate between different pages of the application.

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Context API
- React Router DOM
- Axios
- React Toastify
- LocalStorage
